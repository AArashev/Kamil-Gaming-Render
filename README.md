# Kamil Gaming — 3D Interior

Interactive 3D model of the Kamil Gaming club in Arkach Mall, Ashgabat: a 12-seat main hall, two 5-seat VIP rooms and the reception area.

**▶ Open the 3D viewer:** https://aarashev.github.io/kamil-gaming-3d/

[![Kamil Gaming 3D interior](preview.jpg)](https://aarashev.github.io/kamil-gaming-3d/)

In the viewer you can drag to rotate, scroll or pinch to zoom, switch the ceiling on and off, show PC numbers, and jump to a top-down plan view.

## Location

Arkach Mall, Magtymguly Ave, Ashgabat — near Ertugrul Gazi Mosque, 1st microdistrict.

## Model file

[`kamil-gaming-3d.glb`](kamil-gaming-3d.glb) (glTF binary). It opens in Blender, Windows 3D Viewer, or any glTF viewer.
